# MEZOO INSTALLER BOT

بوت واتساب واحد باستخدام Node.js وBaileys مع ردود ذكاء اصطناعي.

## المتطلبات
- Node.js 20 أو أحدث.
- مفتاح API صالح من OpenAI (استخدام API قد يتطلب رصيدًا منفصلًا عن اشتراك ChatGPT).
- استضافة تسمح بتشغيل Node.js وحفظ مجلد `auth_info` بشكل دائم.

## التشغيل محليًا
1. ثبّت Node.js.
2. نفّذ `npm install`.
3. انسخ `.env.example` إلى `.env`.
4. أضف مفتاح API في `OPENAI_API_KEY`.
5. نفّذ `npm start`.
6. امسح QR من واتساب > الأجهزة المرتبطة > ربط جهاز.

## تفعيل الرد في جروب
- يجب أن يرسل مشرف الجروب `!enable`.
- لإيقافه: `!disable`.
- القائمة: `!menu`.

البوت لا يرد في أي جروب قبل موافقة مشرفه. توجد حدود افتراضية للردود لتقليل الإزعاج واستهلاك API.

## النشر
ارفع الملفات إلى مستودع GitHub الخاص. أضف متغيرات البيئة في لوحة الاستضافة، ولا ترفع `.env` أو `auth_info`.
تأكد أن الاستضافة تدعم تخزينًا دائمًا لمجلد `auth_info` وإلا قد تحتاج لإعادة ربط واتساب بعد إعادة التشغيل.

## ملاحظات
- Baileys مكتبة غير رسمية تتصل بواتساب ويب؛ قد تتغير أو تتعطل، واستخدامها قد يخالف شروط واتساب أو يؤدي إلى تقييد الحساب.
- لا تستخدم البوت للإرسال الجماعي أو الرسائل غير المرغوبة.
- الاستضافة المجانية قد تنام أو تمسح الملفات أو تفرض حدودًا؛ لا يوجد ضمان تشغيل 24/7.
- لا تشارك QR أو ملفات `auth_info` أو مفاتيح API مع أي شخص.
